# ⚜️ MC Trilhas - Downloads

Bem-vindo ao repositório oficial de distribuição do **MC Trilhas**.

Este projeto é um plugin customizado para servidores Minecraft (Paper/Spigot) com temática escoteira, focado em sistemas de insígnias, economia e minigames.

Embora o código-fonte do projeto seja privado, disponibilizamos aqui os artefatos compilados para uso.

## 📥 Como Baixar

Para obter a versão mais recente do plugin:

1.  Clique na aba **[Releases](../../releases)** (ou olhe a barra lateral direita).
2.  Selecione a versão mais recente (marcada como "Latest").
3.  Na seção **Assets**, clique no arquivo `.jar` para iniciar o download.

## 🚀 Instalação

1.  Pare seu servidor Minecraft.
2.  Coloque o arquivo `.jar` baixado na pasta `/plugins`.
3.  Inicie o servidor.
